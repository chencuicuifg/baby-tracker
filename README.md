# 宝宝记录 App

## 功能
- 一键记录尿尿和便便
- 左右母乳计时
- Formula 快捷奶量
- 今日汇总、撤销、CSV 导出
- 数据只保存在当前设备浏览器的 localStorage 中
- 支持添加到 iPad 主屏幕和离线使用

## 发布到 GitHub Pages
1. 新建一个 GitHub repository，例如 baby-tracker。
2. 上传本文件夹里的所有文件到仓库根目录。
3. 打开仓库 Settings → Pages。
4. Build and deployment 中选择 Deploy from a branch。
5. Branch 选择 main，文件夹选择 /(root)，保存。
6. 等待 GitHub 给出网站地址。

## 添加到 iPad 主屏幕
1. 用 Safari 打开发布后的网站。
2. 点分享按钮。
3. 点“更多”，再点“添加到主屏幕”。
4. 名称可改成“宝宝记录”，然后点添加。

## 数据说明
记录默认只保存在当前 iPad。清理 Safari 网站数据、删除浏览器数据或更换设备可能导致数据丢失，请定期导出 CSV。
